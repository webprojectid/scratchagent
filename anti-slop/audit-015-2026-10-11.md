# Unified dark/light palette audit

## Intent

Keep ScratchAgent's green identity across marketing, account, developer and PRD interfaces. Dark mode remains the default for the existing product. Light mode uses neutral off-white, charcoal and a deeper green rather than a bright-white or pastel palette. Energy 2, rhythm inherited from existing layouts, motion 2.

## Changes and checks

- Canonical colors are maintained in color-styles.css. UI utilities, CSS modules, charts and diagram configuration reference the same semantic tokens.
- Purple, blue and orange UI accents and selectable legacy palettes were removed. Old saved choices migrate to Scratch Green, retaining language, layout and other preferences.
- Appearance controls work by click and preserve the selected mode across navigation and reload. Existing account APIs save the additional display field.
- Light-mode selected tabs and solid action buttons use the inverse action label color. Secondary copy uses readable neutral text.
- Free, Pro and Admin retain distinct labels and icon geometry; Pro and Admin share the green palette, with existing motion preferences preserved.
- Canvas resolves actual token colors; WebGL preview colors use green shades. Mermaid rendering refreshes when the theme changes.
- Automated checks verify normal-text contrast of at least 4.5:1 for body, secondary copy, links, actions, errors and every activity-calendar intensity in both modes. Strong form boundaries meet 3:1.
- Browser checks covered homepage, pricing, settings, dashboard, project roadmap, PRD and documentation. Settings and dashboard were checked at 390px without page overflow.
- Final production build and scoped lint passed; 109 regression tests passed.
- Screenshot evidence: artifacts/theme-light-settings.png and artifacts/theme-dark-settings.png.

## Boundaries

Photographs and third-party media remain content assets, not UI palette colors. Browser checks used the public read-only project demo and account preview; admin authorization is covered by existing regression tests, not by impersonating an admin. Existing unrelated generation and CLI edits are excluded from this release.

Source changes were applied directly through source patches. No external rewrite helper or runtime color-inversion layer was added. This audit covers the requested palette and theme changes; it does not claim a new audit of every inherited marketing claim, third-party media pixel or unrelated feature.
