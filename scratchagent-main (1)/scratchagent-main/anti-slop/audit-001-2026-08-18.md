# Anti-Slop Audit 001 — 2026-08-18

Scope: integrasi `galaxy-interactive-hero-section` + frame Safari dark-mode di
halaman sample web project (commit feat: galaxy hero in dark Safari frame).

File yang diaudit:
- `src/components/ui/galaxy-interactive-hero-section.tsx`
- `src/components/ui/safari-browser-frame.tsx`
- `src/components/ui/hero-spline-basic-demo.tsx`
- `src/app/sample/web-project/page.tsx`

## Findings

### 1. [HIGH] R-02 — Em dash di copy hero
Teks referensi mengandung dua em dash:
"Manage all of your media and assets — video, photos, design files, docs,
PDFs, and more — on a single secure surface..."
R-02 melarang em dash di teks UI. Sudah dibawa apa adanya dari referensi.
Fix: ganti dengan koma/titik dua.

### 2. [HIGH] R-26 / R-24 — Link & tombol mati di hero sample
Navbar sample (`Features/Enterprise/Resources/Pricing`, dropdown items,
`Contact Sales`, `Sign In`, CTA `Start Free Trial` hero + tombol
`Watch the Video`) semuanya `href="#"` tanpa tujuan / tanpa onClick.
Konteks: ini memang konten demo (sample website hasil generate), tapi R-26
minta setiap elemen interaktif berfungsi atau diberi label jelas.
Fix: anchor ke section nyata di dalam sample, atau hapus elemen yang tidak
punya tujuan, atau beri label "demo".

### 3. [MEDIUM] R-10 — Glassmorphism melebihi dosis
Blur dipakai di navbar sample + 3 dropdown + menu mobile (5 elemen).
Dosis R-10: maksimal 1-2 elemen blur. Konteks: bagian dari tampilan sample
(meniru referensi), bukan chrome Scratch Agent sendiri.
Fix: turunkan blur hanya di navbar, dropdown pakai solid.

### 4. [MEDIUM] R-32 — Dropdown hanya hover, tidak keyboard-accessible
Dropdown navbar sample muncul via `group-hover` saja; tidak ada
`focus-within`/`focus` path, jadi user keyboard tidak bisa membuka dropdown.
Fix: tambah `group-focus-within:` atau buat dropdown klik-toggle.

### 5. [LOW] R-25 — Kontras label "SECURE" di frame
Teks `text-white/30` (10px mono) di atas `#1F2023` di bawah ambang AA.
Konteks: elemen dekoratif chrome frame, bukan konten; tapi aturan kontras
tetap menyebut semua teks.
Fix: naikkan ke white/45-50.

### 6. [LOW] R-20 / R-29 — Sample product tanpa identitas jelas
Sample website memakai aksen ungu (#8200DB) + abu tanpa nama/logo/brand
tersendiri (navbar pakai logo bulat generik dari referensi). Wajar sebagai
demo, tapi kalau ini dipajang publik sebagai "hasil generate", identitasnya
terlalu generik.
Fix: opsional — beri sample nama/logo sederhana atau biarkan sebagai demo
anonim dengan catatan.

## Lulus (tidak jadi finding)
- R-03 mobile: tidak ada overflow horizontal di 390px (verified)
- R-17/R-36: tidak ada statistik/klaim palsu
- R-23: asset dari referensi yang user minta eksplisit
- R-27: Spline punya loading + error fallback (via SplineScene)
- R-35: dijalankan & diuji (parallax, mobile menu, gambar load)
- R-01 gradient overlay: bertujuan keterbacaan teks di atas scene 3D
- R-38 placeholder jujur: "Other Content Below" eksplisit placeholder
